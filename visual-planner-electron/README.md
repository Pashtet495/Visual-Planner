# Visual Planner — Electron

Десктопная версия «Визуального Планировщика» на базе Electron для Windows.

## Состав проекта

```
visual-planner-electron/
├── package.json              — конфигурация npm и electron-builder
├── main.js                   — главный процесс Electron (окна, диалоги, IPC, протокол vpfile://)
├── preload.js                — безопасный мост между интерфейсом и системой (contextBridge)
├── run.bat                   — запуск приложения без сборки
├── build.bat                 — сборка установщика через electron-builder
├── build/
│   └── icon.png              — иконка приложения
└── app/
    ├── index.html            — разметка (исходный HTML-файл, подключены внешние скрипты)
    ├── styles.css            — оригинальные стили приложения
    ├── attachments.css       — стили вложений, модальных окон и подсветки drag&drop
    ├── app.js                — оригинальная логика приложения + точки интеграции
    ├── electron-integration.js — нативное сохранение/загрузка рабочих пространств
    └── attachments.js        — модуль вложений (скрепка, drag&drop, просмотрщик)
```

## Требования

- Windows 10/11 (64-bit)
- Node.js LTS: https://nodejs.org (при сборке и запуске нужен доступ в интернет для загрузки зависимостей)

## Быстрый запуск без сборки

1. Скопируйте папку `visual-planner-electron` на компьютер с Windows.
2. Запустите `run.bat` — при первом запуске установятся зависимости, затем откроется приложение.

## Сборка установщика (electron-builder)

1. Запустите `build.bat`.
2. Результат в папке `dist`:
   - `Visual Planner Setup 0.5.0.exe` — установщик (NSIS, с выбором папки и ярлыками);
   - `Visual-Planner-Portable-0.5.0.exe` — портативная версия одним exe-файлом.

## Что изменилось по сравнению с HTML-версией

### Работа с файлами рабочих пространств (браузерные «костыли» убраны)

- Сохранение (`Ctrl+S`, кнопка дискеты) — системный диалог «Сохранить как» только при первом
  сохранении; повторные сохранения пишут в тот же файл напрямую, без диалогов.
- «Сохранить как...» (`Ctrl+Shift+S`, кнопка рядом с дискетой) — всегда открывает диалог.
- Загрузка (кнопка с папкой, `Ctrl+O` или меню File → Open Workspace...) — системный диалог
  «Открыть файл» вместо скрытого `<input type="file">`.
- Перетаскивание JSON-файла рабочего пространства на пустое место по-прежнему предлагает
  «Открыть как новое рабочее пространство / Добавить как сабграф», при этом путь к файлу
  запоминается и Ctrl+S обновляет именно этот файл.
- Иконка папки на вкладке показывает полный путь к файлу при наведении.

### Вложения (ссылки на локальные файлы)

- Кнопка-скрепка 📎 добавлена:
  - в правую панель свойств (секция «Вложения»);
  - в всплывающее окно свойств блока (шестерёнка рядом с блоком);
  - в контекстное меню блока (правый клик → «Вложения...»).
- Меню добавления позволяет задать **название документа** (отображается в свойствах блока),
  выбрать файл и добавить комментарий.
- У каждого вложения есть кнопки: 👁 — открыть во встроенном просмотрщике (для форматов,
  поддерживаемых Chromium: PDF, картинки, видео, аудио, текст), ✎ — редактировать название,
  комментарий и путь (замену файла), 📂 — показать файл в Проводнике, ✕ — удалить ссылку.
- Клик по названию вложения открывает файл тем приложением, которое ассоциировано
  в Windows (как двойной клик в Проводнике).
- При наведении на название показывается полный путь к файлу (плюс комментарий).
- Встроенный просмотрщик открывает файл в модальном окне поверх интерфейса с кнопками
  «Закрыть» (✕ в заголовке и кнопка внизу), а также «Открыть во внешнем приложении»
  и «Показать в папке». Файлы отдаются через внутренний протокол `vpfile://` с поддержкой
  перемотки видео/аудио.

### Drag & drop из Проводника

- Перетаскивание файла **на блок** (граф или канбан) — открывается модальное окно
  с названием и комментарием; блок подсвечивается при наведении.
- Перетаскивание файла **на пустое место** — создаётся заметка с вложением (имя заметки
  = имя файла). JSON-файл рабочего пространства при этом по-прежнему импортируется
  как рабочее пространство/сабграф.

### Данные

- Вложения хранятся в файле сохранения (`.json`) и в локальном автосохранении — массив
  `attachments` у блока: `{ name, path, comment }`. Старые файлы сохранений совместимы.
- Автосохранение в localStorage продолжает работать (данные приложения хранятся в профиле
  пользователя Windows: `%APPDATA%/visual-planner`).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Ctrl+S | Сохранить рабочее пространство |
| Ctrl+Shift+S | Сохранить как... |
| Ctrl+O | Открыть рабочее пространство |
| F12 | Инструменты разработчика |
| Esc | Закрыть модальное окно вложения/просмотрщика |
